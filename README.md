# X-Newfish

**给 X 时间线做减法。** 过滤不想看的内容，查看帖子流速，从本页已加载的帖子里找到值得停留的内容。

免费使用 · MIT 开源 · 无需额外注册或激活 · 设置保存在本机

[**下载最新版安装包**](https://github.com/eighteentang/x-newfish/releases/latest/download/x-newfish.zip) · [版本与更新记录](https://github.com/eighteentang/x-newfish/releases) · [反馈问题](https://github.com/eighteentang/x-newfish/issues)

> 当前为基础版，持续迭代中。适用于电脑端 Chrome / Microsoft Edge 的 X 网页版；目前通过开发者模式安装，未提供商店安装入口。无需编程、Node.js 或编译。正常浏览 X 仍需满足 X 自身的登录与访问要求。

## 能做什么

| 功能 | 使用方式 |
|---|---|
| 内容过滤 | 按关键词、账号、语言、链接域名折叠帖子；域名支持子域名 |
| 流速徽章 | 查看发布以来的平均浏览量 / 小时，悬浮查看互动与数据来源 |
| 最低流速过滤 | 开启开关并设定阈值，折叠低于阈值的帖子 |
| 本页排行榜 | 按平均流速、浏览量、点赞或收藏排序；支持时间范围、Top 10 / 20 / 50、定位原帖 |
| 分页面设置 | 首页、列表、个人主页、详情与回复可分别设置，也可继承全局规则 |
| 恢复与白名单 | 查看过滤原因，临时恢复帖子，或将作者设为始终保留 |
| 疑似 AI 评分 | 分别计算账号自动化与本帖 AI 证据分；达到 80 分时显示黄色框及 AI 下标，悬浮查看规则与样本数 |
| 账号受限提示 | X 返回已知受限状态时，显示红框及橙色问号；两个标记开关默认关闭 |
| 关系管理 | 手动只读扫描本人的关注列表，区分未回关、发现取关与状态待确认；支持忽略和 CSV 导出 |
| 趋势监测 | 观察关键词、账号或具体帖子的网页采集样本，支持过去 24 / 72 小时和北京时间昨天 |
| 可移动榜单 | 拖动标题自由移动，收起为屏幕边缘方向按钮，支持上下拖动、恢复及重置位置 |

本项目聚焦时间线阅读与筛选，不提供回复生成或个人风格分析；成人引流识别尚未实现。

## 下载安装：第一次使用从这里开始

### 1. 下载并解压

1. 点击上方 **下载最新版安装包**，保存 `x-newfish.zip`。也可以打开 [Releases](https://github.com/eighteentang/x-newfish/releases/latest)，在 **Assets** 中选择 `x-newfish.zip`。
2. **完整解压 ZIP**。解压后会得到 `x-newfish` 文件夹，打开它应能直接看到 `manifest.json`。
3. 将该文件夹放在长期保留的位置，例如 `文档/浏览器扩展/x-newfish`。安装后不要删除或随意移动它，浏览器会继续读取其中的文件。

正确的目录结构：

```text
x-newfish/
├── manifest.json       ← 安装时选择这一层文件夹
├── background.js
├── content.js
├── options.html
├── icons/
└── …
```

> 不要在压缩包预览里操作，也不要只下载一个 JS 文件。若选择了 GitHub 的 `Source code (zip)` 或 `Code → Download ZIP`，同样需要完整解压；找到直接包含 `manifest.json` 的文件夹即可，无需运行任何命令。

### 2. 加载到浏览器

| 浏览器 | 在地址栏输入 |
|---|---|
| Chrome | `chrome://extensions/` |
| Microsoft Edge | `edge://extensions/` |

1. 打开对应的扩展管理页面，开启 **开发者模式**。
2. 点击 **加载已解压的扩展程序**（部分版本显示“加载解压缩的扩展” / “Load unpacked”）。
3. 选择上一步的 **`x-newfish` 文件夹**：这一层里面必须有 `manifest.json`。选择文件夹，不是 ZIP，也不是 `manifest.json` 文件本身。
4. 页面中出现 **X-Newfish** 且开关处于开启状态，即完成加载。
5. 在浏览器右上角的扩展菜单中找到 X-Newfish，将它固定 / 显示到工具栏，方便打开设置。

官方操作参考：[Chrome 加载已解压扩展](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)、[Edge 本地加载扩展](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)。

### 3. 打开 X，确认已生效

1. 打开 [x.com](https://x.com/) 并正常登录；已经打开的 X 页面请刷新一次。
2. 浏览时间线，有数据的帖子旁会出现流速徽章。缺少浏览量或发布时间的帖子可能显示“流速等待”，这不代表安装失败。
3. 点击工具栏上的 **X-Newfish** 图标，打开设置弹窗（Popup）。确认右上角总开关处于开启状态。

初次安装默认显示流速徽章和本页排行榜；**语言过滤、最低流速过滤和账号标记默认关闭，关键词与黑名单默认留空**，可按需要配置。

## 首次设置建议

### 常用

控制流速徽章和本页排行榜。设置弹窗分为 **常用 / 过滤规则 / 榜单** 三个标签页；常用页的 **关系管理 / 趋势监测** 按钮会打开独立管理页面，名单和图表不挤在 Popup 内。

### 账号提示（常用页）

“疑似 AI 标记”和“账号受限提示”可分别开启，初次安装默认关闭，升级保留已有开关。头像下的标识与外圈不占页面布局空间；开启 AI 标记后，悬浮可定位的作者头像可查看本次评分（包括零分）、原因和检测时间。Popup 点击保存设置后，下方会显示已检查帖子、账号资料覆盖、可定位头像及实际标记数，帮助区分未取得资料与未达到阈值。

- **黄色框 + AI**：账号自动化分 A 与当前帖子 AI 分 C 分开计算，综合分 S=max(A,C)，不相加。达到 80 分才加框；60–79 分待观察，低分或未知不代表真人。分值是规则证据强度，不是 AI 概率，权重尚未通过标注样本校准。自动化不一定使用生成式 AI，提示中会注明。账号证据仅用于当前已加载的同账号帖子，帖子声明不扩散到作者其他帖子。
- **红框 + 橙色 ?**：仅依据 X 返回的 `fake_account`、`timeout` 或 `suspended` 等已知状态，提示账号受限，不代表恶意账号。关注数为零、粉丝少或发帖多不会单独触发。
- **识别边界**：本地规则不调用模型、不新增网络请求，无法可靠识别普通 AI 代写或润色；单纯讨论 AI、名字含 AI、文风工整不会触发。引用、代码、否定和疑问形式的声明会尽量排除。没有证据或没有匹配的本帖作者头像时不显示，未标记不代表纯人工或正常账号。
- 黄色和红色提示可同时显示。关闭对应开关即移除对应标识，关闭总开关移除所有标记；本次不增加自动屏蔽或取关操作。

完整分值、重复样本门槛、时间规律弱证据、同源封顶与排除规则见 [AI 评分说明](docs/AI_SCORING.md)。

### 配置过滤规则

先将“作用页面”设为 **全局默认**，确认“在此页面应用过滤”已开启，再按需求配置：

- **关键词**：开启关键词过滤，要隐藏的关键词每行一个，例如“广告”“抽奖”。这里只按填写的关键词匹配，不会自动识别所有广告。
- **语言**：开启语言过滤，选择“仅中文”或“中文 + English”，也可填写 `zh`、`en`、`ja`、`ko` 等语言代码。允许列表里的语言会保留；无法确认语言的帖子也会保留。
- **最低流速**：开启最低流速过滤，并填写大于 `0` 的阈值。例如 `100` 表示折叠平均浏览量低于 `100/h` 的帖子。`0` 表示不过滤；数据不足的帖子会保留。
- **屏蔽账号与链接**：填写 `@用户名` 或域名，每行一个。例如 `example.com` 同时匹配 `shop.example.com`，但不匹配 `fakeexample.com`。
- **始终保留的账号**：白名单在所有页面生效，优先于包括账号黑名单在内的所有过滤规则。

想让首页过滤更严格、回复区保留完整上下文？选择对应的“作用页面”，关闭 **使用全局规则** 后单独设置；也可关闭该页面的过滤。重新开启“使用全局规则”会移除该页面的独立配置。搜索等其他页面使用全局规则，回复弹窗使用“详情与回复”规则。

**开关更改后立即保存；输入框在编辑结束后保存，也可以点击底部“保存设置”。** 留意底部反馈：会提示保存状态，以及 X 页面已检测、已过滤和有数据的帖子数量；页面未响应时会提示重新加载。

被过滤的帖子会显示原因，点击 **显示这条** 可临时恢复，点击 **重新隐藏** 可收起；修改规则后会重新评估。点击 **始终保留 @用户名** 可将作者加入白名单。

### 榜单

设置排序依据、发帖时间范围（全部 / 最近 1 小时 / 24 小时 / 7 天）、显示条数、背景不透明度及收起状态。点击榜单条目可在当前页面定位并高亮帖子，点击“原帖”可在新标签页打开。

**榜单只统计当前页面已加载、且未被过滤的帖子，不是全站热门榜。** 缺少排序指标的帖子不参与排名；按发帖时间筛选时不包含时间未知的帖子。关闭徽章不会关闭榜单，可分别控制。

拖动榜单标题可移动位置，松手后保存。点击收起后，主体隐藏，只留下贴在左／右屏幕边缘的约 `24 × 36px` 方向按钮；可上下拖动按钮，点击恢复浮窗。窄窗口继续保留入口，窗口大小变化会校正位置。位置异常时，在榜单或 Popup「榜单」中点击 **重置位置**。

## 关系管理：未回关与发现取关

1. 打开并登录 X，更新扩展后先刷新 X 页面。
2. Popup「常用」→ **关系管理** → **读取 X 账号**，选择本次要扫描的账号。
3. 点击 **开始扫描**。插件会新开本人的关注页，读取该页面正常加载的分页并自动滚动；不会主动调用关注／取关接口。
4. 保留扫描页面，等待结果；可随时在管理页或扫描页点击 **停止**。关注页会显示已读取数量，扫描停止后会留下原因，可手动关闭提示。连续 90 秒没有有效分页或总时长达到 30 分钟时停止并保留部分结果；后台若超过两分钟收不到页面心跳，也会结束任务。数量上限按关注账号计算，与粉丝数无关。
5. 管理页查看未回关、发现取关、状态待确认，按名字、蓝 V 筛选，忽略账号或导出 CSV。仅展示前 100 条，导出包含全部筛选结果。

**首次完整扫描只建立基线，不能追溯之前谁取关过你。** 历史中曾互关、当前我仍关注对方、对方明确不再关注我时，才显示发现取关。显示的是发现时间，不是准确取关时间；关闭浏览器期间不承诺持续检测。

分页必须从首屏连续到末页。未知字段、限流、超时、关闭扫描页、账号切换或未读完整，都会保留上次完整记录；可勾选查看最近的部分结果，但部分结果不用于判定取关。缺失关系保持未知，不默认当作未回关；受限账号单独显示，关注数为零不代表恶意或受限。数据按登录用户 ID 隔离，最多保留 3 个账号的完整记录，单次最多 3000 个关注账号。当前版只提供打开主页，不代替用户取关或批量取关。

## 趋势监测：关键词、账号、具体帖子

1. Popup「常用」→ **趋势监测**，选择关键词／短语、`@账号` 或完整帖子链接，添加目标（最多 10 个）。
2. 点击 **打开 X 搜索**，在 X 的最新结果中滚动加载。搜索词只是入口，网页返回结果可能不完整；帖子关联和时间在本机再次筛选。
3. 回管理页点击 **读取已加载页面** 或 **刷新本机结果**，查看过去 24 小时、72 小时或北京时间昨天的采集样本。
4. 查看讨论帖、去重参与者、回复、引用、转发事件及去重转发者；可导出当前窗口的全部已采集记录。

### 统计口径

- **讨论帖**＝匹配的原创、回复、引用，排除纯转发；账号监测中也排除目标账号自己的发帖。
- **参与人数／转发者人数**按用户 ID 去重，缺失 ID 的记录不冒充可确认人数。
- **转发事件**必须是有明确发布时间的转发帖子；仅有当前累计转发数或转发者列表不能推断昨天的转发次数。
- **转发累计净变化**需要窗口开始前及结束前可比较的本机快照；显示实际快照时间与可比原帖数量，可为负，不等于转发次数或人数。缺少快照不填零，不事后伪造昨日数据。
- **粉丝数净变化**需本机存在本人账号的可比快照，不归因于某个关键词或帖子；关系扫描时可采集页面返回的本人粉丝数。
- **昨天**按北京时间昨日 `00:00–24:00`，不同于过去 24 小时。图表按小时展示；空白时段表示缺失，不表示零讨论。窗口比较只显示各自采集量，不计算全站涨跌幅。

**所有结果都是网页已采集样本，不是 X 全站总量。** 只保存匹配已添加目标的内容，不自动全站抓取；浏览器关闭时不持续采集。重读页面缓存保留原响应时间，不会把旧数据伪装成当前观测。近期内容、快照保留 7 天，最多 2000 条匹配帖子、6000 个小时快照；正文摘要最多 1500 字，关联引用／转发摘要有额外长度限制。容量不足时优先淘汰较旧观察内容，界面显示容量淘汰计数。

## 后续如何更新

开发者模式安装的版本**不会自动更新**。

1. 从 [最新版本](https://github.com/eighteentang/x-newfish/releases/latest) 重新下载 `x-newfish.zip` 并完整解压。
2. **保持原安装文件夹路径不变**，将新版 `x-newfish` 文件夹中的全部文件覆盖到原文件夹中。不要套成 `x-newfish/x-newfish/`。
3. 回到 `chrome://extensions/` 或 `edge://extensions/`，点击原有 X-Newfish 卡片的 **重新加载 / 刷新** 按钮。
4. 再刷新已打开的 X 页面；打开设置，确认版本号已更新。

保留原扩展卡片并在原路径更新，通常可以继续使用已有设置。**请勿先卸载再安装**，卸载会清除该扩展在本机的设置。早期自行加载源码的用户也按此方式更新原有文件夹，无需重新安装一份。

## 常见问题

### 提示“无法加载清单”或“找不到 manifest.json”

请先完整解压，再选择直接包含 `manifest.json` 的文件夹。常见原因是选中了外层目录、ZIP 文件，或解压时只保留了部分文件。

### 保存了规则，但没有过滤

依次检查：总开关、当前页面的“在此页面应用过滤”、对应过滤开关；最低流速阈值需要大于 `0`。确认允许语言的方向是“保留”，并检查作者是否在白名单、当前页面是否有独立规则。最后查看设置底部是否显示已应用；若页面未响应，请先重新加载扩展，再刷新 X。仅刷新 X 不会更新扩展脚本。

### 徽章显示“流速等待”或读数和页面有差别

数据来自 X 已发出的响应，并在必要时使用本帖页面读数补充。首次打开页面后可滚动加载更多帖子；缺少数据时不会编造数值，页面缩写数字还可能存在舍入误差。悬浮详情会标明来源。

流速是 **发布以来的平均浏览量 / 小时**，不是最近一小时新增浏览量。发布不足 5 分钟时按 5 分钟计算，以减少短时间波动。

### 找不到榜单

确认“本页排行榜”开启，查看屏幕左右边缘是否有收起箭头；可在 Popup「榜单」中重置位置。空榜单时检查当前已加载、未过滤的帖子是否具有所选排序指标，尝试滚动或切换排序依据。

### 管理页无法读取账号或扫描显示部分结果

先确认已登录 X；更新扩展后需重新加载扩展并刷新 X 页面，再点击读取账号。X 若没有返回明确关系字段，插件会保留未知。页面结构、不可见账号、分页错误或限流都可能使本次不完整；不要将部分扫描当成完整取关名单。扫描结果不会追溯安装前历史，也不会在浏览器关闭后自动运行。

### 找不到扩展图标 / 浏览器不让开启开发者模式

从扩展菜单中找到并固定 X-Newfish。若浏览器受公司或学校策略管理，可能不允许加载本地扩展，需要使用允许安装的浏览器环境。手机端 X App、Safari 和 Firefox 不在当前安装说明的支持范围内。

### 如何停用或卸载

临时停用可关闭 Popup 右上角总开关，或在浏览器扩展管理页面关闭 X-Newfish。卸载时在扩展管理页面点击“移除”；卸载会清除本机设置。

## 数据与权限

- 仅在 `x.com` / `twitter.com` 网页运行，使用浏览器 `storage` 权限保存设置。
- 指标取自页面已经发出的 GraphQL 响应，不额外请求 X 接口；域名过滤优先读取已展开链接，不额外访问短链或猜测短链目的地。
- 设置、关系记录与监测数据在本机处理，无需创建产品账号、填写 API Key 或激活码；本项目没有用于收集设置或帖子数据的服务端。管理页可导出数据；删除监测目标会移除仅属于该目标的采集记录。
- X 页面和数据结构可能变化，兼容性需要持续维护；当前模拟检查不能替代真实登录 X 后的使用验收。

## 开发与打包

本项目是 Chrome Manifest V3 扩展，没有构建步骤和运行时依赖。开发时直接加载仓库根目录即可。

```bash
node dev/selftest.js
node dev/browser-check.js
```

浏览器模拟检查入口：`http://127.0.0.1:18763/`；设置界面：`/options`；附带布局检查：`/options?check=1`。检查覆盖过滤、恢复、白名单、分页面规则、路由切换、榜单和回复弹窗徽章边界；不连接真实 X 账号。

维护者打包（需要 Python 3，普通用户无需运行）：

```bash
python dev/package-release.py --out ../x-newfish-release/x-newfish.zip
```

打包脚本仅收录运行所需文件、许可及 README 使用的赞助图片，检查清单和脚本引用，不包含开发检查页、本地工作记录或 Git 数据。压缩包内固定使用 `x-newfish/` 目录，方便用户按原路径更新。
