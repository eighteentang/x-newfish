# 本地 AI / 自动化线索评分

规则分表示已观察证据的强度，**不是 AI 概率，也不是账号真人认证**。这些权重为本地启发式，未经标注数据集校准；自述真实性没有经过核实。只读取当前网页已取得的数据，不调用模型、不上传评分材料、不要求密钥。

## 两条分数轴

- A（automationScore）：账号自动化证据分。
- C（contentScore）：当前帖子 AI 参与证据分。
- S（score）= max(A, C)，不把账号与帖子线索相加。
- A = max(账号强证据中的最高分, min(50, 行为线索合计))。
- C = max(当前帖子强证据中的最高分, min(40, 格式线索合计))。

80–100 为 `high`，可进入原有 `ai` 原因数组并显示提示框；60–79 为 `observe`，仅待观察；0–59 为 `insufficient`，表示证据不足。当前版本的弱线索合计最高40分，暂不会单独达到待观察档。没有线索、低分或缺少样本均不等于真人。平台自动化标签也不等于使用生成式 AI。

## 强证据规则

| 证据 code | 范围 | 分数 | 条件 |
| --- | --- | --- | --- |
| platform_automated | account | 85 | X 返回明确自动化标签 |
| bio_ai_operated | account | 90 | 简介以当前账号/本人为主体，明确自述 AI 驱动运营，或明确自称 AI 机器人/助手/代理 |
| bio_bot | account | 80 | 简介明确自述机器人或自动化账号 |
| post_ai_generated | post | 90 | 当前正文以本帖/本文/本回复等为主体，明确声明使用 AI 生成或撰写 |
| post_ai_assisted | post | 85 | 当前正文明确声明 AI 辅助生成、修改、润色或翻译；不代表全文生成 |
| post_model_identity | post | 80 | 当前正文出现完整的“作为/我是一个 AI 语言模型/助手”或英文对应身份自述；身份后要求标点或句末 |

只支持代码列出的中英文句式和模型名称，未命中可能只是表达不在规则覆盖范围内。开发者、研究者等身份后缀不会被当作完整机器人或模型自述；单纯讨论 AI、职业、头像、认证、粉丝数、分点写作或文字工整均不加分。

## 行为与格式弱线索

样本只供行为统计，不从其他帖子提取 AI 声明，不将其他帖子的身份残留传给当前帖子。调用方必须保证样本来自同一个账号。

每次最多使用输入尾部200条，按帖子 ID 去重；无 ID、无文本、转发样本排除。`sampleCount` 为此步骤剩下的样本数量，不代表账号全部历史。

| 证据 code | 分数 | 明确前提 |
| --- | --- | --- |
| observed_repetition | 20 或30 | 至少10条去引用后不少于20字符的原创/回复；至少5条全文相同且占这些样本至少50%时20分；若该重复组涉及至少5个不同被回复帖子则30分。两种线索只取一次，合计≤30。不同 replyToId 只是不同被回复帖子，不保证属于不同会话树。 |
| observed_regular_timing | 10 | 至少20个不同有效时间，跨度≥6小时；所有相邻间隔≥1分钟，间隔标准差/平均值≤0.15。定时发布或采集偏差也可能满足，不足以证明无人值守。 |
| post_protocol_residue | 15 或25 | 当前正文去引用后有模型协议标记（例如 `<\|im_start\|>`、`<\|assistant\|>`、`[INST]`）；一个15分，两个及以上25分。技术讨论可能出现同样标记，因此不能单独加框。 |

重复文本仅折叠空白并转小写；不做模糊语义判断。行为总上限50，当前实现最高40；格式/文风总上限40，当前协议残留最高25，没有额外文风加分。弱证据不会叠加到强证据之上。

## 防误报与局限

代码块、行内代码、成对引号内文字、Markdown 引用行先排除；被排除内容保留占位符，防止把引用两边拼成新的命中句。按句子/换行切分，排除疑问与常见否定表达，再对句首主体和完整词尾匹配。没有问号时，句中明确的“吗/么/是吗/对吗/真的吗”及句末英文“right/correct/really/is that true/is it”等疑问尾语也会抑制命中；紧随“说法/声明/断言”等词出现“假/错误/不实”等驳斥，或英文“that claim is false”等表达，同样不会当作有效自述。英文 `right after` 等未落在句末的普通表达不按疑问尾语处理。正则无法理解全部语境，特别是讽刺、跨句驳斥、未闭合引号、间接转述和罕见否定形式；不能声称已经识别所有引用和否定。账号限制提醒独立保留在 `warning`，不计 AI 分，也不代表恶意。

## 接口

`normalizeAccount(user)` 保留原有字段规范化行为。

`classify({ account, text, samples = [] })` 返回：

- `ai: string[]`、`warning: string[]`：兼容原调用。只有≥80的强证据写入 `ai`。
- `automationScore`、`contentScore`、`score`：上述 A、C、S。
- `level: 'high' | 'observe' | 'insufficient'`。
- `evidence: { code, scope: 'account' | 'post' | 'observation', points, reason }[]`：展示命中与局限；逐项 points 不能直接相加成总分。
- `sampleCount: number`：去重过滤后的观察数。

样本形状：`{ id, text, createdAt, replyToId, isRepost }`。时间使用毫秒 Unix 时间戳或可解析日期字符串；不可解析时间不参与间隔统计。当前帖子的 text 单独传入，样本内其他帖子的 AI 声明不会影响 C。

## 验证范围

本次遵照用户要求仅做 JavaScript 静态语法检查，未新增或运行测试套件。规则准确率、真实 X 字段覆盖率与登录网页兼容性未由此验证。
